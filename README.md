# AI-Powered E-Commerce Data Analytics

## Project Overview
An end-to-end e-commerce data analytics project that analyzes 5,000 orders and generates business insights using Python, SQL, Power BI, Google AI Studio, and Lovable.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / MySQL
- Power BI
- Google AI Studio
- Lovable

## Dataset
The dataset contains 5,000 e-commerce orders with information about:
- Orders
- Customers
- Product Categories
- Regions
- Quantity
- Revenue
- Discounts
- Payment Methods
- Delivery Days
- Customer Ratings

## Key Insights
- Total Orders: 5,000
- Total Revenue: ₹51,09,775.74
- Total Quantity Sold: 20,224
- Best Product Category: Electronics
- Best Region: West
- Most Used Payment Method: Card
- Average Customer Rating: 2.97
- Average Delivery Days: 6.12
- Best Sales Month: August 2026

## Dashboard
Created an interactive Power BI dashboard with KPIs, charts, and filters for product category, region, and payment method.

## AI Insights
Google AI Studio was used to generate AI-powered business insights from the e-commerce dataset.

## Objective
To transform raw e-commerce data into meaningful business insights and an interactive analytics solution.
